# Documentação do Portal UI

Escolha o ponto de partida que corresponde ao seu momento:

1. [Primeira tela com Portal UI](getting-started.md) — instalação completa em um Laravel novo.
2. [Autenticação](authentication.md) — proteção das páginas e configuração das rotas de login e logout.
3. [Integração SenhaÚnica](senhaunica.md) — views tematizadas, LoginAs, usuários e autorização administrativa.
4. [Solução de problemas](troubleshooting.md) — sintomas, causas e comandos de diagnóstico.
5. [Exemplos](examples.md) — configurações e componentes para telas mais completas.

O tutorial inicial deve ser seguido antes dos demais. Ele estabelece o contrato básico entre uma página da aplicação, o layout local e o layout fornecido pelo pacote.
